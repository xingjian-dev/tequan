xPAM 控制台原型

凭据管理与密码生命周期管理

总览 保险库 生命周期 无密码接入 证书与密钥 审计中心

应用无密码接入 (Secretless)

应用动态获取最新凭据，实现“不内嵌、不落地”。支持多种对接方案，确保改密后应用连接不中断或平滑恢复。

📦
SDK API 对接 最灵活
在应用代码中引入 xPAM SDK，通过标准化接口实时或缓存拉取凭据。适合内部自研应用。
  • 支持 Java, Go, Python, Node.js
  • 提供受控下发与短期内存缓存
  • 提供轮换回调通知机制 (Callback)
🚗
Sidecar 代理注入 云原生
作为独立进程与应用容器同 Pod 部署，拦截请求并自动注入凭据。应用零代码改造。
  • 业务代码 0 侵入，无需修改配置
  • K8s 原生支持，自动注入环境变量
  • 支持统一的可观测性与拦截审计
🗄️
定制 JDBC 驱动 数据库专享
替换原生 JDBC 驱动，在数据库连接建立阶段动态注入凭据。适合老旧单体应用或中间件。
  • 支持动态改密，应用不中断
  • 兼容主流连接池 (HikariCP, Druid)
  • 内置连接重建策略与失败回退

import com.xpam.sdk.client.XPamClient; import com.xpam.sdk.model.Credential; // 1. 初始化客户端 (认证信息可通过环境变量注入) XPamClient client = new XPamClient("https://xpam-api.internal"); // 2. 获取凭据 (自动处理缓存与轮换) Credential cred = client.getCredential("MySQL-Trade-RW"); // 3. 使用凭据连接 String dbUser = cred.getUsername(); String dbPass = cred.getPassword();

* 注意：该凭据已配置“使用后即换”策略，调用后凭据将被系统自动轮换。
